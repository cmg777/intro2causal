# Spanish home-page mind maps

`full/` holds WebP exports (RGB, quality 90, native 1672 × 941) of the approved Spanish chapter maps in
`mindmaps/es/images/`, produced by `scripts/export_spanish_mindmaps.py`. `index-es.html` references them
through `i18n/home/translations.json`; provenance is in `mindmaps/es/manifest.json`.
