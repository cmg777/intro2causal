# Episode mind maps

Six original square mind maps, regenerated with the built-in image generation
tool at the user's request for simplified Spotify episode artwork. Each uses four
branches, a large chapter title, and one takeaway. The existing widescreen mind
maps remain the reference materials for the book and website.

The selected generated PNGs were exported as 2048 × 2048 RGB using Lanczos
resizing, without cropping. Individual `*-prompt.txt` files preserve the prompts.
Chapter 5 received a second image-generation pass to replace line charts with
simple symbolic illustrations and avoid implying misleading pre-trend slopes.
