The Furious Five

A visual overview of the methods

Five methods to separate cause from correlation.

01

RCT

Randomized trials

ATE = E[Y1] − E[Y0]

Random assignment eliminates selection bias

02

OLS

Regression

Y = α + βX + ε

All confounders are observed and controlled

03

IV

Instrumental variables

βIV = Cov(Y, Z)Cov(D, Z)

Instrument affects Y only through D

04

RD

Regression discontinuity

τ = limcutoff Y+ − limcutoff Y−

No manipulation of the running variable

05

DiD

Differences-in-differences

δ = (YT,post − YT,pre)− (YC,post − YC,pre)

Parallel trends in the absence of treatment
